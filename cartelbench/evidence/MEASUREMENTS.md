# Measurements

Every number the backend claims, with the command that produced it. Result files are written by scripts in this repository and start with `Generated by <command> at <time> from commit <sha>. Do not edit by hand.` (JSON: keys `generated_by` and `commit`). Nothing here is typed in by hand except this table.

The main session copies each row into `hackathon/FACTS.md`; only from there do numbers go into the report and the README. When a value changes, add a new row with a new key and name the old key in "Replaces".

Every row is checked before each commit: the result file exists, carries the header and names a commit of this repository. Commands run from the repository root unless noted; `cartelbench/` commands run inside `cartelbench/`.

## Notes on provenance

- The payoff table in `data/payoff_table.csv` is reconstructed from the four anchor cells quoted in the idea card (header of the file says so). In the reconstruction the best reply to 9 is 5 (322 points), not 7 (296 points); the paper's example of undercutting to 7 is reproduced exactly, the rest of the table is not the paper's. Runs made before the transcription of Table 1 are valid as runs of this table and must be repeated once the published table is in place if the report claims the paper's payoffs.
- The human values in `data/human_baseline.json` are from the 2009 working paper as transcribed by the ideas session; the comparison with the RAND 2012 version is open (the cloud session cannot reach the publishers).
