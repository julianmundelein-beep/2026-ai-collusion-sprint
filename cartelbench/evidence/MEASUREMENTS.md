Every row is checked before each commit: the result file exists, carries the header and names a commit of this repository. Commands run from the repository root unless noted; `cartelbench/` commands run inside `cartelbench/`.

## Open measurements (need the Anthropic key)

Planned keys, filled in as rows above once the files exist:

- M10, one real call through the harness client (hello world of the model layer): `python3 -m cartelbench.smoke --model claude-haiku-5-5` (inside `cartelbench/`), file `evidence/smoke/smoke_claude-haiku-5-5.json`.

- M13, contamination, whether each model names the paper when asked: `python3 -m cartelbench.contamination --model <model>`, file `evidence/contamination/contamination_<model>.json`.
- M20 to M23, four core regimes, 20 duopoles, main model, the measures of PREREGISTRATION.md with cluster-bootstrap intervals: `python3 -m cartelbench.run --regime <regime> --model <model> --duopoles 20 --seed <n>`, then `python3 -m cartelbench.analyze --bootstrap evidence/runs/<run_id>`, files `evidence/runs/<run_id>/summary.json`.
- M30, scorecard x of 8 and Figure 1: `python3 -m cartelbench.scorecard --model <model>`, files `evidence/scorecard/scorecard.json` and `figure1_scorecard.png`.

## Notes on provenance

- `data/payoff_table.csv` is the transcription of Table 1 of the paper (IFN WP 738, 2011 version, `hackathon/private/sources/`); `python3 cartelbench/scripts/make_payoff_table.py` checks all 169 cells against the paper's demand model (M07). The reconstruction used before 2026-10-24 18:00 HKT is withdrawn; no model run was made with it.
- The human values in `data/human_baseline.json` are from Tables 3, 4 and 5 and Section 5.2.3 of the 2011 version. The comparison with the published RAND 2012 version is still open (not available in the cloud); the 2011 version is the one revised for it.
- Design corrections made after the paper check are listed in `PREREGISTRATION.md`, amendment 2.
