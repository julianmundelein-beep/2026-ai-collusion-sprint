# Judges' guide: ten minutes

1. **The claim and the picture (2 minutes).** The first screen of the root [`README.md`](../README.md) states the question (do fines, leniency and rewards act on LLM sellers as on humans, and what reaches the coordination they leave behind?), shows the main figure (`cartelbench/evidence/round7/diagonal.png`: the announced screen threshold becomes the price) and gives three more findings with their numbers. The report is [`paper/CartelBench_AI-Collusion-Research-Sprint_2026.pdf`](../paper/CartelBench_AI-Collusion-Research-Sprint_2026.pdf); the numbers in README and report are the same, and `paper/report.md` mirrors the report's text.
2. **Registered before the runs (1 minute).** Open [`cartelbench/PREREGISTRATION.md`](../cartelbench/PREREGISTRATION.md). The commit that added it (`git log --follow cartelbench/PREREGISTRATION.md`, aeb16a0 at 2026-10-24 08:47 UTC) predates every model call in `cartelbench/evidence/`; every later amendment is a dated section committed before the runs it governs, and round 7 and the open models have their own files (`PREREGISTRATION_round7.md`, `PREREGISTRATION_provider2.md`, `PREREGISTRATION_stage2.md`). The run ledger [`cartelbench/evidence/ledger/ledger.md`](../cartelbench/evidence/ledger/ledger.md) binds every run folder of rounds 1 to 6, including the nine aborted ones, to its section and hashes its files, and names the one exception (a Sonnet run started four minutes before amendment 3); round 7 runs are logged at start in `cartelbench/evidence/round7/launches.jsonl` and `launch_log.jsonl`.
3. **The human comparison (2 minutes).** The primary scorecard, [`cartelbench/evidence/round4/scorecard_haiku_8pool/scorecard.md`](../cartelbench/evidence/round4/scorecard_haiku_8pool/scorecard.md): one row per published result, human value next to the LLM value, yes or no by the pre-registered rule (3 of 7 tested results reproduced), with the 4-pool scorecard next to it (`scorecard_haiku_4pool/`, 2 of 7) and the permutation tests in `round4/scorecards.md`. [`paper/figures/figure1_landscape.png`](../paper/figures/figure1_landscape.png) is the same table as a figure.
4. **One run, line by line (2 minutes).** Pick any run in `cartelbench/evidence/runs/`. `config.json` names the regime, seed, model and payoff table; `calls.jsonl` holds every prompt and answer with token usage; `periods.jsonl` every period; `summary.json` the measures and the counts of refusals, invalid answers and defaulted decisions. `python3 -m cartelbench.analyze <run dir>` recomputes the measures. The README's "Verify a number" walks one claim from the report to its row, file, commit, ledger hash and run.
5. **Positive control first (1 minute).** [`cartelbench/evidence/pilot/pilot_summary.json`](../cartelbench/evidence/pilot/pilot_summary.json) says per model how many late pairing episodes priced above the Nash price 3 in laissez-faire (6 of 6 for each Claude model) and how many answers were refusals (0); Table 1 of the report lists the scripted players and the known-effect arms through the same pipeline (always-collude 1.000 and Nash 0.000 at both ends, instructed cartel 0.984, certain detection 0.000).
6. **What is simulated (1 minute).** The market is a laboratory game, fines are told, not paid; `--player` and `--partner` runs use scripted players and are labelled `provider: scripted`. The payoff table [`cartelbench/data/payoff_table.csv`](../cartelbench/data/payoff_table.csv) is the transcription of the paper's Table 1 (169 cells, checked against the paper's demand model by `cartelbench/scripts/make_payoff_table.py`). [`DESIGN_NOTES.md`](DESIGN_NOTES.md) lists every known deviation from the paper.
7. **Rerun the tests (1 minute).** `pip install -e cartelbench && sh cartelbench/scripts/run_tests.sh` (129 passed, 1 skipped without torch; no API needed). Every number of the report has a row in [`cartelbench/evidence/MEASUREMENTS.md`](../cartelbench/evidence/MEASUREMENTS.md) (Claude models, rounds 1 to 6), [`MEASUREMENTS_round7.md`](../cartelbench/evidence/MEASUREMENTS_round7.md) (round 7) or [`provider2/MEASUREMENTS_provider2.md`](../cartelbench/evidence/provider2/MEASUREMENTS_provider2.md) (Qwen and Llama, stage 2) with the command, the result file and the commit. The Cartel Risk Cards ([`cartelbench/evidence/risk_cards/summary.md`](../cartelbench/evidence/risk_cards/summary.md)) condense the per-model measures on one page each.
