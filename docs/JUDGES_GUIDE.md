# Judges' guide: ten minutes

1. Read the first screen of the root README: the question (do fines, leniency and rewards act on LLM sellers as on humans, and what reaches the coordination they leave behind?), the method (the published experiment replayed with the same rules) and the three findings. The report itself is `paper/CartelBench_AI-Collusion-Research-Sprint_2026.pdf`; the numbers in README and report are the same.
2. Open `cartelbench/PREREGISTRATION.md`. The commit that added it (`git log --follow cartelbench/PREREGISTRATION.md`) predates every model call in `cartelbench/evidence/`; every later amendment is dated and was committed before the runs it governs. The run ledger `cartelbench/evidence/ledger/ledger.md` binds every run folder, including aborted ones, to its amendment and hashes its files.
3. Open the primary scorecard, `cartelbench/evidence/round4/scorecard_haiku_8pool/scorecard.md`: one row per published result, human value next to the LLM value, yes or no by the pre-registered rule, with the 4-pool scorecard next to it (`scorecard_haiku_4pool/`). `paper/figures/figure1_landscape.png` is the same table as a figure.
4. Pick any run in `cartelbench/evidence/runs/`. `config.json` names the regime, seed, model and payoff table; `calls.jsonl` holds every prompt and answer with token usage; `periods.jsonl` every period; `summary.json` the measures and the counts of refusals, invalid answers and defaulted decisions. `python3 -m cartelbench.analyze <run dir>` recomputes the measures.
5. Check the positive control first: `cartelbench/evidence/pilot/pilot_summary.json` says per model how many late pairing episodes priced above the Nash price 3 in laissez-faire and how many answers were refusals; Table 1 of the report lists the scripted players and the known-effect arms through the same pipeline.
6. Check what is simulated: the market is a laboratory game, fines are told, not paid; `--player` and `--partner` runs use scripted players and are labelled `provider: scripted`. The payoff table `cartelbench/data/payoff_table.csv` is the transcription of the paper's Table 1 (169 cells, checked against the paper's demand model by `cartelbench/scripts/make_payoff_table.py`).
7. Rerun the tests: `sh cartelbench/scripts/run_tests.sh` (no API needed). Every number of the report has a row in `cartelbench/evidence/MEASUREMENTS.md` or `cartelbench/evidence/provider2/MEASUREMENTS_provider2.md` with the command, the result file and the commit.
