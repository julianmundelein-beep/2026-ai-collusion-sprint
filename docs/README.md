## Generated files (every one starts with `Generated by <command> at <time> from commit <sha>`)

| Folder | Command | Content |
|---|---|---|
| `../cartelbench/evidence/runs/`, `provider2/runs/`, `round7/runs/`, `stage2/runs/` | `python3 -m cartelbench.run ...` | one folder per run: `config.json`, prompts, `calls.jsonl` (every call), `periods.jsonl`, `summary.json` |
| `../cartelbench/evidence/pilot/` | `python3 -m cartelbench.pilot` | positive control per model |
| `../cartelbench/evidence/contamination/` | `python3 -m cartelbench.contamination` | cloze probes: does the model know the paper's numbers |
| `../cartelbench/evidence/scorecard/`, `scorecard_sonnet/`, `round4/scorecard_*` | `python3 -m cartelbench.scorecard`, `python3 -m cartelbench.round4 scorecards` | scorecards against the eight human results; the primary one is `round4/scorecard_haiku_8pool/` |
| `../cartelbench/evidence/round4/`, `round5/`, `round6/`, `round7/` | `python3 -m cartelbench.round4 <block>` and so on | the analyses of each round; `round7/diagonal.png` is the main figure |
| `../cartelbench/evidence/provider2/round5/`, `round7/` | `python3 scripts/provider2_round5.py`, `provider2_round7.py` | the same analyses for the open models |
| `../cartelbench/evidence/risk_cards/` | `python3 cartelbench/scripts/risk_card.py` | Cartel Risk Cards: `summary.md`, one page per model, `risk_cards.json` |
| `../cartelbench/evidence/ledger/` | `python3 cartelbench/scripts/ledger.py` | run ledger: every run folder hashed and bound to its registration section; `launches.jsonl` |
| `../cartelbench/evidence/scripted/` | `python3 cartelbench/scripts/scripted_baseline.py` | naive baseline with scripted players |
| `../cartelbench/evidence/tests/` | `sh cartelbench/scripts/run_tests.sh` | test log |
| [`figures/`](figures/) | `python3 docs/figures/make_overview.py`, `python3 docs/figures/make_header.py` | overview of the four models from the risk cards (`model_overview.png`, values in `model_overview.json`); the README header banner (`header.svg`, typeface of the report template); the README cartoon (`cartoon.svg`, hand-drawn, animated) |

## Checks

- `sh cartelbench/scripts/run_tests.sh`: the test suite, no API.
- `python3 cartelbench/scripts/check_links.py`: every relative link and image in the Markdown files of the tree resolves to a file.
